# References

Read the matching source before you use an external API or language feature.

Odin's vendor packages live under the Odin root. This repository's `vendor/` holds only Box3D.

## Odin

- Language docs: `~/Projects/odin/references/docs`
- Core library: `~/Projects/odin/references/Odin`
- Vendor bindings: `~/Projects/odin/references/Odin/vendor`
- Examples: `~/Projects/odin/references/examples`

## Box3D

- Odin bindings: `vendor/box3d/*.odin`
- C source: `vendor/box3d/src`
- Compiled archive: `vendor/box3d/lib/linux-amd64/libbox3d.a` (generated by `make`)

## SDL3 and Vulkan

- SDL3 bindings: `~/Projects/odin/references/Odin/vendor/sdl3`
- SDL3 headers: `~/Projects/odin/references/Odin/vendor/sdl3/include`
- Vulkan bindings: `~/Projects/odin/references/Odin/vendor/vulkan`
